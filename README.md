## Overview
A professional portfolio website showcasing creative work across UI/UX design, graphic design, digital art, and professional experience. The website serves as a comprehensive display of projects and capabilities.

## Features
- 🎨 Responsive grid-based gallery layout
- 📱 Mobile-friendly design
- 🖼️ Interactive image lightbox
- 🔄 Smooth scrolling functionality
- 📑 Categorized project sections
- 🔍 Detailed project views
- ⚡ Fast loading times

## Technology Stack
- HTML5
- CSS3
- JavaScript (Vanilla)
- Responsive Design
- Git Version Control

## Local Development
1. Clone the repository:
   ```bash
   git clone https://github.com/Hanbee17/portfolio_hanbeecho.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio_hanbeecho
   ```
3. Open `index.html` in your browser or use a local server:
   ```bash
   python -m http.server 8000
   ```
4. Visit `http://localhost:8000` in your browser
